# Автотесты для API Яндекс.Диска
Проект сделан в рамках тестового задания по автоматизации тестирования API Яндекс.Диска.

## Запуск прокта
### Запуск по маркерам

```bash
pytest -m collection # запустить всю коллекцию тестов
pytest -m create_and_delete_folder # создание и удаление папки
pytest -m upload_and_delete_file # загрузка и удаление файла
pytest -m trash_delete_and_restore # удаление и восстановление файла
pytest -m replace_file # перемещение файла в другую папку
```

### Запуск через main.py

```bash
python main.py
```

## Описание проекта
Проект выполнен на Python 3.13 с использованием пакетов requests и pytest

### Структура проекта

```
api_test/
    base_api.py        # базовый класс для работы с HTTP-запросами
    steps.py           # утилитарные действия клиента для тестовых сценариев
    yandex_api.py      # реализация методов для API Яндекс.Диска

tests/
    test_files/        # тестовые файлы
    test_yandex.py     # тесты API

.env                  # окружение
config.py             # конфигурация
conftest.py           # фикстуры pytest
pytest.ini            # настройки pytest
requirements.txt      # зависимости
main.py               # точка входа для запуска тестов
```

### Реализованные тестовые сценарии
* создание и удаление папок
* загрузка и удаление файлов
* работа с корзиной (удаление и восстановление)
* перемещение файла в другую папку
